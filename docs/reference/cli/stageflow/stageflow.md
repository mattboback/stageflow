## stageflow

StageFlow CLI

```
stageflow [flags]
```

### Options

```
      --api string       API base URL (default "http://localhost:8080")
      --api-key string   API key
      --format string    Output format: text, markdown, or json (default "text")
  -h, --help             help for stageflow
```
