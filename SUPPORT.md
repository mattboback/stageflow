# Support

## Where to Ask Questions

- **Bugs / reproducible problems:** GitHub Issues
- **Feature requests:** GitHub Issues

If you open an issue, include:

- What you are trying to do
- Your environment (OS, Podman version, Go/Bun versions)
- Relevant logs (redact secrets)
- Reproduction steps (if applicable)

## Scope

StageFlow is a self-hosted platform. Support is best-effort and focuses on:

- Reproducible bugs in supported configurations
- Documentation fixes
- Security vulnerabilities (see `SECURITY.md`)

We can’t guarantee help for custom infrastructure troubleshooting or production incident response.
