# Security Policy

## Supported Versions

Security fixes are provided on a best-effort basis for:

- The latest tagged release
- The `main` branch

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Preferred: report via **GitHub Security Advisories** for this repository.

If private reporting is not available, open an issue requesting a private channel and include **only high-level** details (no exploit payloads, no sensitive URLs, no credentials).

## What to Include

- Impact and affected component(s) (API, orchestrator, extractor, scanner-runner, frontend)
- Minimal reproduction steps or a proof of concept (sanitized)
- Version/commit SHA
- Any mitigations you’ve identified

## Disclosure

We’ll acknowledge reports, triage severity, and coordinate a fix/release. Timing is best-effort.
