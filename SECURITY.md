# Security Policy

## Reporting a Vulnerability

Please report security issues privately via GitHub Security Advisories:

1. Open the repository Security tab.
2. Create a private vulnerability report.
3. Include impact, reproduction steps, and suggested remediation.

Do not open public issues for active vulnerabilities.

## Scope

This policy covers:

- StageFlow services in this repository
- Deployment and runtime configuration shipped in this repository
- Bundled scanners and plugin loading behavior

## Response

- Triage acknowledgment target: 3 business days
- Initial severity assessment target: 7 business days
- Critical issues are prioritized ahead of feature work
